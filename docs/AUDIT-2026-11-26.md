## Make it better: the "PC worker" done properly

The goal: bots can tidy your PC, but can never lose anything.

1. **Real tools, run by plain code (not the AI):** list folder, read file (with a size cap), search, find duplicates, folder sizes, create folder, move/rename, copy. **There is no delete tool.**
2. **Plan, then approve.** The bot writes a change plan (e.g. "move 214 files from Downloads to F:\Archive\2026-11"). The dashboard shows the exact list, total size and anything unusual. You approve the whole batch in one click.
3. **Every change is logged and undoable.** Each batch gets a journal, and "Undo batch" puts everything back.
4. **"Delete" means quarantine.** Items move to `F:\DDG_Quarantine`. You empty it yourself, with a 30-day reminder.
5. **Always-blocked list**, whatever the scope: Windows, Program Files, AppData, credential and key folders, `.git` folders, browser profiles, game installs, and the studio's own permission files.
6. **Real checks instead of the fake vote:** last opened, in a git repo?, duplicate?, size, on the blocked list?
7. **Dry run first.** Every plan runs as a simulation and shows the result before anything moves.

This would have prevented this morning's model mess: a cleanup run as plan, quarantine and undo can't silently lose 8 GB of models.

## Make it better: the employee side

- **Real data in the briefs:** Heimdall's 7am brief reads DDG Control (bot reports, alerts), GitHub (open PRs, failing checks), DDG Finance status and the crypto bot's results. At most 5 items, each with its source.
- **One team:** local bots read and post to the DDG Control message board, so the Grok bots and the local bots share one picture.
- **Each bot gets only its own tools,** and its prompt lists exactly those tools and nothing more.
- **Honest status:** every message that states a fact shows where it came from; "I can't do that yet" is allowed.
- **Phone alerts** for anything waiting on you (approvals, quarantine, crypto bot down).

## Make it better: crypto trading helpers

- **Separate program, shared brain.** The crypto bot runs on its own, but uses the same Ollama, with GPU priority over video jobs, so a render never blocks a trading decision.
- **Keep the model loaded** while the bot runs, so it doesn't reload every 5 minutes. Unload it when you start a game (extend the GPU guard to games).
- **Plutus becomes its face.** Plutus is your paused Finance & Analytics bot; it would report the crypto bot's trades and daily profit and loss. The bot prompt rule "trading is forbidden" needs a narrow change: paper-only crypto on this PC.
- **Record every price tick** locally, so rule changes can be replayed on recorded data (forward-recorded only, no hindsight).
- **Watchdog plus a heartbeat to DDG Control,** so a crash or reboot shows up as "missed", never silently.
- **A daily one-line result** in Heimdall's 7am brief.
