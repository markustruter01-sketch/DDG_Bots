# DDG Bot Studio audit — 28 Nov 2026

Markus: "it never stays online, comes back broken, crypto stuck at $100k, replies are jagged, the UI is bad, the AI is
too restricted." Every finding below is tied to a log, file or code line read on 28 Nov (PC files staged ~11:39 AEST).

## Verdict
The studio is not mainly held back by its safety rules. It is held back by broken plumbing: the AI engine (Ollama)
froze for about 17 hours and nothing noticed or fixed it; a restart breaks any open dashboard tab; and the chat is fed
a prompt and a renderer that make a small model sound stiff.

## Rules question
Removing the safety rules would not make it smarter: it failed because it could not be reached, not because it was
blocked. The protections that matter live in code (no deleting, Markus approves moves, fake money only) and cost no
ability. What makes it *sound* useless is the prompt's long "can't" list and pasted rules — those can go.

## Fix plan
**P1 Reliability**
1. One-time `Fix Ollama Settings.bat` (Markus runs it): saves the model folder and address as Windows settings so every Ollama start finds Qwen.
2. Watchdog also checks Ollama with a tiny question; if it's frozen or can't find Qwen it restarts it properly. Logged.
3. Server and Ollama write logs to `logs\`.
4. The page reloads itself when the studio restarts (no more dead tab).
5. "Start Local LLM" becomes "Restart AI": stops a frozen engine and starts it right.

**P2 Chat quality**
6. New short bot prompt with date and time, no pasted Claude/Replit rules, no "can't" list.
7. Tools always available; the model decides when to use them; add read-only tools (studio status, crypto status, date).
8. Proper markdown (lists, headings, tables, code), smooth streaming, Stop button, longer replies, no 45 s cut-off.
9. Optional: Qwen3.5 9B and a "think harder" switch.

**P3 Interface**
10. Chat-first page like ChatGPT / Claude: conversations on the left, one reading column, settings in a menu.
11. Optional: a cloud model (Claude or Gemini) for chat when you want Claude-quality answers (costs money); Qwen stays free and offline.
